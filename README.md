Python script to download your Snapchat memories by locally hosting HTTP server with memories accessible and move them to your desired folder.

## Running from Source

### Linux / WSL

To create a virtual environment:
- `python3 -m venv env/`

Activate it:
- `source /env/bin/activate`

Install all required packages to run the script in virutal environment:
- `(env) pip install -r ./requirements.txt`

To run the script from source:
- `(env) python -m src.main`
